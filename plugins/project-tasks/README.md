Um painel na barra da esquerda (`Ctrl+Alt+T`) com as tarefas do projeto aberto. Elas ficam num `TAREFAS.md` na raiz do projeto, como checkboxes do Markdown (`- [ ] fazer x`), então dá para editar o arquivo à mão, versionar no git e ler em qualquer lugar.

## Como usar

Escreva e aperte Enter para adicionar. Marque, apague ou **Limpar feitas**. O nome do arquivo muda na engrenagem do plugin.

Com o **Markdown Preview** ligado, o `TAREFAS.md` aberto no editor se redesenha a cada mudança.

## Configurações

Aba Plugins › engrenagem do Project Tasks:

| Configuração | O que muda |
|---|---|
| **Arquivo das tarefas** | o caminho do arquivo, relativo à raiz do projeto (padrão `TAREFAS.md`) |
