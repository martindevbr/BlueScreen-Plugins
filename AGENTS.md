# Instruções para agentes de IA

Este arquivo vale para qualquer assistente de IA (Claude Code, Codex, Cursor, Copilot e afins)
que gere commits, pull requests ou código neste repositório. É obrigatório.

## Commits: nunca marque a IA

**Jamais adicione metadados de IA a um commit ou pull request.** Em especial:

- **Nada de `Co-authored-by:` de IA** (ex.: `Co-authored-by: Claude ...`, `... <noreply@anthropic.com>`).
- Nada de IA como **autor** ou **committer** (`author`/`committer`), nem como signatário.
- Nada de trailers ou textos como `Generated with`, `Generated by AI`, `🤖 ...` ou semelhantes,
  na mensagem do commit **ou** na descrição do pull request.

Se a sua ferramenta inserir qualquer um desses itens sozinha, **remova antes de commitar/enviar**.
Preserve a autoria Git verdadeira de quem fez o trabalho: não invente nem troque a identidade.

A mensagem de commit segue o [CONTRIBUTING.md](CONTRIBUTING.md) (seção **Commits**): curta, clara,
em português, começando pelo plugin quando for de um só (`Exploiter: conserta o crawler`).

## O resto do padrão

Tudo o que o repositório exige de um plugin (manifesto, README com ficha, categorias, versões,
regras de código, servidor só em `127.0.0.1`, sem npm, sem CDN, sem segredos) está no
[CONTRIBUTING.md](CONTRIBUTING.md). Antes de abrir um pull request, rode:

```
node ferramentas/plugins.mjs tudo
node ferramentas/plugins.mjs versoes --base origin/main
```
