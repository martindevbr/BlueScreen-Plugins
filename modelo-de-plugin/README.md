# {{nome}}

Um parágrafo dizendo o que o plugin faz e para quem ele é útil. A ficha acima é gerada a partir do `plugin.json`
(`node ferramentas/plugins.mjs gerar`): não edite à mão.

## Como usar

Onde o plugin aparece (painel, aba, atalho, Buscar em tudo) e o passo a passo do uso mais comum.

| | |
|---|---|
| **Buscar em tudo** | "{{nome}}: dizer olá" mostra a saudação |

## Configurações

Aba Plugins › engrenagem do {{nome}}:

| Configuração | O que muda |
|---|---|
| **Saudação** | o texto que a ação mostra |
